CURRICULUM

Structured Learning Modules

Step-by-step tracks designed for beginners, developers, and system administrators.

Track 1: Linux Fundamentals

Filesystem hierarchy (/etc, /var, /usr), essential navigation (cd, ls, pwd), viewing & manipulating files (cat, less, grep, find, tar).

Track 2: Permissions & Ownership

User & group management, file permission bits, chmod numerical modes, SUID/SGID/Sticky bits, and sudo privileges.

Track 3: Process & Service Management

Managing daemons with systemctl & journalctl, inspecting processes with ps, top, htop, kill signals, and background jobs.

Track 4: Networking & Remote Access

SSH key generation and port forwarding, IP routing (ip, netstat, ss), DNS lookups (dig, nslookup), curl & wget.

Track 5: Storage, Disks & LVM

Partitioning with fdisk, mounting filesystems, monitoring disk usage (df, du), and Logical Volume Manager (LVM) basics.

Track 6: Security & DevOps Automation

Firewall setup with UFW & iptables, bash scripting fundamentals, cron scheduling, and Docker container integration.
